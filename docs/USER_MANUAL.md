## 快速开始

### 1. 登录系统

访问平台地址，使用管理员分配的账号密码登录：

**演示账号**：
- 管理员：`admin@smartua.com` / `admin123`
- 优化师：`optimizer1@smartua.com` / `optimizer123`
- 分析师：`analyst1@smartua.com` / `analyst123`
- 财务：`finance@smartua.com` / `finance123`

### 2. 切换 App（租户）

登录后，点击右上角 **App 切换器**，选择要操作的应用。平台采用**行级数据隔离**，不同 App 的数据完全独立。

### 3. 首次使用流程

```
登录 → 选择 App → 查看 ROI360 大盘 → 检查 Campaign 健康度 → 使用自然语言执行操作
```

## 角色与权限

### 预定义角色

| 角色 | 权限说明 | 典型用户 |
|------|---------|---------|
| **admin** | 系统全部权限，可管理用户和 App | 平台管理员 |

## ROI360 数据分析

### 核心指标体系

ROI360 提供全链路转化漏斗分析：

| 指标 | 说明 | 计算方式 |
|-----|------|---------|
| **ROI D0** | 首日回本 | 首日收入 / 花费 |
| **ROI D3** | 3日回本 | 3日累计收入 / 花费 |
| **ROI D7** | 7日回本 | 7日累计收入 / 花费 |
| **ROI D14** | 14日回本 | 14日累计收入 / 花费 |
| **ROI D30** | 30日回本 | 30日累计收入 / 花费 |
| **CPI** | 获客成本 | 总花费 / 安装量 |
| **Retention D7** | 7日留存 | 第7日留存用户 / 安装用户 |

### 维度下钻分析

支持多维度组合筛选：
- 媒体平台：Meta / Google / TikTok
- 国家地区：US / JP / UK / DE 等
- 时间范围：日 / 周 / 月
- 账号 / Campaign / AdSet / Ad

### 常用分析场景

1. **花费趋势分析**：按日查看花费、收入、ROI 趋势
2. **渠道对比**：各媒体平台的 ROI 表现对比
3. **国家分析**：各地区的 CPI 和留存对比
4. **Campaign 排名**：按 ROI 排序找出 Top/Bottom Campaign

## Campaign 健康监控

### 健康度评分体系

| 健康等级 | 评分范围 | 说明 |
|---------|---------|------|
| 🟢 **优秀** | 80-100 | ROI 达标，稳定放量中 |
| 🟡 **良好** | 60-79 | 表现正常，有优化空间 |
| 🟠 **警告** | 40-59 | 指标下滑，建议干预 |
| 🔴 **危险** | 0-39 | 严重问题，立即处理 |
| ⚪ **待投放** | - | 新建/草稿状态 |

### 健康度构成

```
健康总分 = ROI 分 (40%) + 留存分 (25%) + 花费稳定性 (20%) + 规模化潜力 (15%)
```

### 自动告警

系统自动检测异常并触发告警：

| 告警类型 | 触发条件 | 严重程度 |
|---------|---------|---------|
| **ROI 暴跌** | 日环比下降 > 30% | 高 |
| **CPI 飙升** | 日环比上升 > 50% | 高 |
| **花费突降** | 日花费低于预期 > 50% | 中 |
| **留存下滑** | 7日留存下降 > 20% | 中 |
| **零花费** | Campaign 连续 3 天零花费 | 低 |

## 四层运营实体模型

### 实体层级关系

```
┌───────────────────────────────────────────────────────────┐
│                        Campaign (活动)                      │
│  └── budget, bid strategy, targeting, status               │
└───────────────────────────────────┬───────────────────────┘
                                    │
                      ┌─────────────▼─────────────┐
                      │      AdGroup (广告组)     │
                      │   └── audience, budget    │
                      └─────────────┬─────────────┘
                                    │
                         ┌──────────▼──────────┐
                         │     Ad (广告)       │
                         │  └── creative, bid  │
                         └──────────┬──────────┘
                                    │
                      ┌─────────────▼─────────────┐
                      │   Creative (素材)          │
                      │   └── image/video/html     │
                      └────────────────────────────┘
```

### 各层级说明

| 层级 | 关键字段 | 典型操作 |
|------|---------|---------|
| **Campaign** | 国家、平台、目标、出价策略、日预算、总预算 | 开关、调预算、改出价 |
| **AdGroup** | 受众定向、素材组、组预算 | 调整受众、启停素材组 |
| **Ad** | 关联素材、出价 | 启停单广告、调价 |
| **Creative** | 素材类型、文件大小、尺寸、标签 | 上传新素材、轮换优化 |

### 标准状态流

**所有层级统一状态流转**：

```
draft → approved → api_submitted → running → paused → ended
```

| 状态 | 说明 |
|------|------|
| **draft** | 草稿，未提交到媒体平台 |
| **approved** | 审批通过，待提交 |
| **api_submitted** | API 提交成功，媒体平台处理中 |
| **running** | 正常投放中 |
| **paused** | 已暂停 |
| **ended** | 投放结束 |

### 下钻操作示例

1. **Campaign 列表页** → 点击某 Campaign → **Campaign 详情页**
2. **Campaign 详情页** → AdGroup 列表 → 点击某 AdGroup → **广告创意列表**
3. **创意列表** → 点击素材 → **素材详情页** → 查看表现数据

- 按设计师筛选
- 按标签搜索
- 按状态筛选（投放中/已暂停/草稿/归档）

**数据指标列**：
| 指标 | 说明 |

- 🔼 上升
- ➡️ 稳定

**性能指标卡片**：
```

│  花费   │ 展示     │ 点击     │ CTR      │
```

**关联 Campaign / AdGroup**：
- 列出当前素材关联的所有广告组

### 素材优化建议

系统自动识别低表现素材并建议：
1. **高花费低 CTR** → 建议更换创意或优化首帧
2. **高 CTR 低转化** → 建议优化落地页或受众定向
3. **表现好但量小** → 建议放量，增加预算
4. **表现稳定但衰减** → 建议轮换新素材

**一句话完成投放操作，无需在多层菜单中寻找功能。**

```

```

## 操作安全分级

### 四级安全矩阵

| 等级 | 人机模式 | 审批要求 | 超时策略 | 典型场景 |
|-----|---------|---------|---------|---------|
| **L0** | Human-on-the-loop | 无需审批 | 立即执行 | 素材轮换、告警检查、报表生成 |
| **L1** | 一键确认 | 可选审批 | 10 分钟超时自动执行 | 暂停低 ROI Campaign<br>预算调整 ±20% |
| **L2** | Human-in-the-loop | 必须审批 | 不自动执行 | 提价 > 50%<br>单日提额 > $1000 |
| **L3** | 仅建议 | 完全人工 | 永不自动 | 新建 Campaign<br>大策略调整 |

### 审批流程

```
L0 级别:
用户输入 → 系统解析 → ✅ 立即自动执行

L1 级别:
用户输入 → 系统解析 → 显示确认弹窗 →
  ├─ 用户点击确认 → 立即执行
  └─ 10 分钟无操作 → 自动执行

L2 级别:
用户输入 → 系统解析 → 提交审批 →
  ├─ 审批人同意 → 执行
  └─ 审批人拒绝 → 终止

L3 级别:
用户输入 → 系统解析 → 仅给出建议 → 用户手动执行
```

### 超时自动执行说明

- **目的**：避免优化师因会议、下班等无法及时操作而错过优化窗口
- **可取消**：在 10 分钟窗口期内可随时取消自动执行
- **通知**：执行前 1 分钟发送提醒通知

## 策略模板

### 模板概念

将常用优化策略保存为模板，一键应用到符合条件的 Campaign。

### 内置系统模板

| 模板名称 | 适用场景 | 风险等级 |
|---------|---------|---------|
| **低 ROI 暂停** | ROI < 0.5 且花费 > $100/天 | L1 |
| **高 ROI 放量** | ROI > 1.5 且 CPI 稳定 | L1 |
| **周末加预算** | 周末 ROI 表现更好的计划 | L2 |
| **夜间降出价** | 夜间转化差的时段优化 | L1 |
| **新计划保护** | 新建 7 天内的计划不自动暂停 | L0 |

### 自定义模板

创建自定义策略模板：

```json
{
  "name": "美国区 ROI 优化策略",
  "conditions": [
    {"metric": "country", "operator": "=", "value": "US"},
    {"metric": "roi_7", "operator": "<", "value": 0.6},
    {"metric": "daily_spend", "operator": ">", "value": 200}
  ],
  "actions": [
    {"type": "pause_campaign"}
  ],
  "auto_execute": false
}
```

## 常见问题

### Q: 大模型不可用时会怎样？

A: 系统设计了**降级机制**：
- 规则引擎继续工作，支持基础操作
- 自然语言解析降级为关键词匹配
- 提示用户"高级功能暂时受限"
- 所有核心数据功能完全正常

### Q: 如何查看操作历史？

A: 在「操作日志」页面可查看：
- 所有意图执行记录
- 审批流程记录
- 实际 API 调用日志
- 效果回扫结果

### Q: 数据更新频率？

A:
- 实时数据：每 1 小时同步一次
- 聚合指标：每日凌晨重新计算
- 健康评分：每日更新
- 告警检测：每 15 分钟检测一次

### Q: 支持哪些媒体平台？

目前支持：
- Meta (Facebook/Instagram)
- Google Ads
- TikTok Ads

可通过连接器扩展更多平台。
