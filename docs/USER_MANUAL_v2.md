## 1. 快速开始

### 登录
访问平台地址，使用管理员分配的账号密码登录。

**演示账号**：
- 管理员：`admin@smartua.com` / `admin123`
- 优化师：`optimizer1@smartua.com` / `optimizer123`
- 分析师：`analyst1@smartua.com` / `analyst123`
- 财务：`finance@smartua.com` / `finance123`

### 首次使用流程
```
登录 → 选择 App → 查看 ROI360 大盘 → 检查 Campaign 健康度
     → （新）用「智能体控制台」下目标 / 查看主动自治告警
```

> ⚠️ **Agent 端点需 JWT**：使用「智能体控制台」前请先登录；未登录调用 `/agent/*` 会返回 401。

## 2. 平台概览

| 维度 | 传统平台 | SmartUA v1 | **SmartUA v2（Agentic）** |
|------|---------|-----------|--------------------------|
| 操作方式 | 菜单+表单 | 自然语言单轮 | **目标驱动多轮 + 主动自治** |
| 决策主体 | 100% 人工 | AI 建议+人把关 | AI 规划+人把关+**系统主动守护** |
| 自动化 | 规则引擎 | 意图+评估+闭环(空壳) | 意图+评估+**真实闭环(记忆/策略)** |
| 安全机制 | 二次确认 | L0-L3 分级 | L0-L3 分级（Agent 与意图共用） |

### 核心功能模块
```
┌────────────┬────────────┬─────────────────┬────────────┬──────────────────┐
│ ROI360 大盘│ Campaign   │ 意图操作中心    │ 素材管理   │ 🤖 智能体控制台   │
│            │ 健康监控   │ (单轮遗留)      │            │ (目标驱动+主动自治)│
└────────────┴────────────┴─────────────────┴────────────┴──────────────────┘
```

## 8. 意图驱动操作（单轮遗留）

> **说明**：`/intent/execute` 是 v1 单轮「解析→弹窗→执行」流程，**保留并存**作为轻量入口。
> 需要多步规划、观察后再决策、回采影响时，请用下方 **🤖 智能体控制台**。

| 意图 | 示例输入 |
|-----|---------|
| 暂停 Campaign | `"把 ROI 低于 0.5 的 Campaign 暂停"` |
| 预算调整 | `"给 ROI > 1.2 的 Campaign 加预算 20%"` |
| 出价调整 | `"把 CPI 高于 8 美金的 Campaign 降价"` |
| 素材轮换 | `"轮换 ROI 低于平均的素材"` |

**AI 解析结果示例**：
```
• 意图类型: campaign.pause
• 置信度: 85.7%
• 风险等级: L1（一键确认）
• 影响 Campaign 数量: 3 个
• 预估每日节省花费: $1,200
```

## 9. 操作安全分级（Agent 与意图共用）

| 等级 | 人机模式 | 审批要求 | 超时策略 | 典型场景 |
|-----|---------|---------|---------|---------|
| **L0** | Human-on-the-loop | 无需审批 | 立即执行 | 素材轮换、观察/筛选/报表 |
| **L1** | 一键确认/人在环 | 需审批 | 不自动（Agent 模式） | 暂停低 ROI、预算调整 ±20% |
| **L2** | Human-in-the-loop | 必须审批 | 不自动 | 调出价 >50% |
| **L3** | 仅建议 | 完全人工 | 永不自动 | 新建 Campaign、大策略调整 |

> **v2 护栏强化**：在 Agent / 主动自治中，**L1/L2 写动作绝不自动执行**——一律生成审批步骤
> 或主动提案，等你批准。仅 L0（如换素材）在低风险场景自动执行。

## 11. 🤖 智能体控制台（Agent Console，v2 新增）

> 入口：左侧菜单「智能体控制台」（RobotOutlined）→ `/agent`。
> 这是 SmartUA 迈向 Agentic 的核心交互面：用**自然语言目标**驱动一个会规划、会多轮、会回采、
> 会记忆、且**主动守护**的投放智能体。

### 11.1 给 Agent 一个目标（多轮对话）

1. 在左侧输入框描述**结果导向**的目标，例如：
   - `暂停 ROI 低于 0.5 的 campaign，给 ROI 最高的加预算 20%，并轮换表现最差的素材`
   - `给高 ROI 的 campaign 加预算提量`
   - `分析一下当前账户表现，给出优化建议`
2. 点「启动 Agent」→ 右侧出现**步骤时间线**：
   - 💭 推理（Thought）
   - 👁 观察（Observation，如账户概览）
   - ✅ 已执行（L0 自动动作 + 回采影响）
   - ⏳ 待审批（L1/L2 高风险动作，内联**批准/拒绝**）
   - 🏁 结论（终态汇总）
3. Agent 在首个 L1/L2 动作处停下（`awaiting_approval`），你在页面点「批准执行」→ 续跑；
   点「拒绝」→ Agent 记住被驳动作并重新规划。
4. 用底部输入框**多轮追问**（如「把加预算幅度收敛到 10%」），Agent 续跑。

### 11.2 人在环审批（Human-in-the-loop）

- **L1/L2 动作**：Agent 只「提议」，页面内联显示预测影响（`predicted_impact`：ΔROI/ΔSpend
  控制 vs 处理），你批准后才真实执行。
- **驳回后**：Agent 把该 (工具, 对象) 记入 `rejected`，避免反复提议同一动作。
- 每个写动作执行后回填 `impact_2h/24h/7d_json`，沉淀为记忆（见 §12）。

### 11.3 智能体大脑（右侧 Tabs）

**🧠 智能体大脑**：
- **已学策略**：展示 Phase 3 学到的可复用参数（加预算增幅上限 / 暂停 ROI 阈值 / 换素材触发下限），
  带置信度与样本量。
  - 「学习策略」：把近期记忆编译为策略参数并落盘（跨账户/重启不丢）。
  - 「重置策略」：清回硬编码默认。
- **经验复盘**：点「复盘记忆」→ 基于已沉淀的 Episode 生成「摘要 + 启发式规则」
  （止损 / 预算边际递减→增幅收敛 / 素材疲劳短期提振 / 提价伤 ROI）。

**🛡 主动自治**（见 §11.4）。

### 11.4 主动自治面板（Phase 4）

> Agent 从「人召唤才动」升级为「主动守护」：后台 APScheduler 周期巡检账户，发现异常自动分级处置。

面板功能：
- **监控状态条**：显示调度开/关、巡检间隔、最近扫描时间、待审批数、当前平台（`mock`）。
  - 开关（Switch）：一键启停主动巡检调度（等价于 `POST /agent/autonomy/toggle`）。
- **立即巡检一次**：手动触发一次巡检（等价于 `POST /agent/autonomy/scan`），返回
  `自动处置 / 待审批 / 仅通知` 统计。
- **告警流**（最新在前）：
  - 异常类型：CPI 飙升 / ROI 跌破 / 素材疲劳 / 花费异常 / 账户被封。
  - 处置状态：
    - ✅ 已自动处置（L0，如换素材）
    - ⏳ 待你审批（L1/L2，如暂停/调预算 → 内联**批准/驳回**）
    - ℹ️ 仅通知（花费异常、账户被封 → 不自动改动，等你判断）
    - 已批准 / 已驳回
  - 「查看会话」：跳转到该主动提案关联的 Agent 会话，看完整推理链。

> **主动≠失控**：L1/L2 高风险动作只生成提案推给你审批；账户被封（Meta appeal）等只告警不自动缩量。
> ROI 止损阈值优先采用 Phase 3 已学策略，随经验自适应。

## 12. 闭环学习（v2 升级为真实闭环）

v1 的「闭环学习」是空壳（schema 预留 `impact_*` 但无回填）。v2 已真实打通：

```
目标 → Agent 规划(ReAct) → 真实执行(经 MockMediaConnector 因果引擎)
     → 回采 2h/24h/7d 影响 → 沉淀 Episode(记忆)
     → 复盘提取规则(反思) → 编译为策略参数(策略自演化)
     → 反哺下次规划(越做越准) → 主动巡检(守护)
```

| 回采时间点 | 回采指标 | 落点 |
|-----------|---------|------|
| 2 小时 | CPA 变化、花费速度 | `impact_2h_json` |
| 24 小时 | ROI 变化、转化量 | `impact_24h_json` |
| 7 天 | 留存、长期 ROI | `impact_7d_json` |

> 当前 `mock` 引擎为确定性模拟（不消耗真实预算），回采基于日粒度模拟，2h 影响为线性外推近似。
> Meta 恢复后切回真实 Connector，回采逻辑不变。

## 13. 常见问题

### Q: 大模型不可用时会怎样？
A: 系统**降级到规则引擎**，Agent 仍可用（确定性规划器把目标拆成多步）；自然语言解析降级为
关键词匹配；所有核心数据功能正常。

### Q: 如何查看操作历史？
A: 「操作日志」页可看意图执行记录、审批流程、API 调用日志、效果回采；Agent 的会话与步骤在
「智能体控制台」可见。

### Q: 数据更新频率？
A: 实时数据每 1 小时同步；聚合指标每日重算；健康评分每日更新；告警每 15 分钟检测；
**主动自治巡检间隔由 `agent_autonomy_interval_seconds` 控制（演示 120s，生产建议 ≥300s）**。

### Q: 支持哪些媒体平台？
A: 连接器支持 Meta / Google / TikTok（设计）；当前因 Meta 被封，`agent_default_platform="mock"`
（因果模拟引擎）作为数据土壤，恢复后改配置即可切回真实 Meta，上层零改动。

### Q: Agent 会自动乱改我的账户吗？
A: 不会。L1/L2 高风险动作**仅在你批准后**执行；仅 L0（换素材等低风险）自动执行；账户被封/
花费异常等只通知不改动。所有写动作均经审计落库。
