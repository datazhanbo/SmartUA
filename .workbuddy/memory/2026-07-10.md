# 2026-07-10 工作日志

## SmartUA 定位评审与 Agentic 升级方案

- 阅读了 README / PROJECT_SUMMARY / ARCHITECTURE / LLM_ROUTING / RELATED_PROJECTS 及实际代码（intent_engine.py、intent.py、IntentCenter.jsx）。
- 核心判断：
  - 当前 SmartUA 不是 "agentic ad platform"，而是「意图驱动的投放控制台」——有对话入口但无 agent 自主循环。
  - 相比原始 ad-agent/ua-monitor（agent+skill）形态，当前平台化版本**丢失了进化能力**：意图引擎是单轮解析（NL→8个硬编码意图→记录），execute() 是模拟（simulated:True），无记忆/反思，impact_2h/24h/7d 字段预留但未回填，IntentCenter 历史用 MOCK。
  - LLM 路由设计（解耦+优雅降级+多模型）是真实亮点，应保留。
- 真正的 ad agent = 目标驱动 + 自主循环（感知-规划-行动-反思-学习）+ 记忆 + 真实执行 + 人在环。
- 升级方向：平台做"身体+护栏"，Agent Loop 做"大脑"，Tool/Skill Registry 桥接（平台 API 注册为带风险元数据的工具，自动映射 L0-L3）。
- 已产出方案文档：docs/AGENTIC_AD_PLATFORM_UPGRADE.md（Phase 0~4 + 最小切片 MVP：真实执行→24h 回采→多轮对话）。
