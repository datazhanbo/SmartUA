- 用户问：目前 Meta 对接方案、Meta MCP 能力/是否接入、MCP/API 返回数据映射与本地存储（计划分层/Report）。

- **数据映射缺口（关键）**：
  1. **计划分层数据无维度表**：fact_media_daily 仅把 campaign/adset/ad/creative ID 当指标字段，无独立层级维度表；`current_summary()` 的 status/daily_budget/creative_age 硬编码 ACTIVE/None（base.py:503）。需新增 `dim_meta_structure`（含 status/budget/bid/targeting/effective_date），由 `pull_structure()` 刷新。

  3. 内部 `campaigns` 表（models/campaign.py）是 SmartUA 自身投放计划，非 Meta 外部结构镜像，别混用。
- **凭证缺口**：Meta 无 `.env` 配置项（resolve_credentials 只给 google 加了 config 回退），需 DB `connector_credentials` 或加 config 字段；沙箱未装 facebook-business。
